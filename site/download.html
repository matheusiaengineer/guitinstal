INSTALL GUIDE · v—

What actually happens after you press download.

GUITinstal is a desktop app that runs on your machine. It reads a public GitHub repository, detects the stack, writes an installation plan, and executes each command only after you approve it. Nothing is installed silently or executed in the cloud. The optional AI assistant sends only the question and recent project evidence you approve, and sends a selected file only when you request a repair.

END TO END

From download to running project.

Eight moments, with the time each one really takes.

  1. 1

    You download one .exe

    A single installer file, about 115 MB. No account, no email, no credit card.

    1–3 min, depends on your connection
  2. 2

    Windows warns you first

    The build is unsigned, so SmartScreen shows "publisher could not be verified". Here is why and what to click.

    10 seconds, once
  3. 3

    The installer copies the app

    You pick the folder, it creates a Start menu and desktop shortcut. Roughly 450 MB on disk.

    about 30 seconds
  4. 4

    First run starts a local server

    The window you see is served by a small Node server bound to 127.0.0.1 on a random port. It never listens on your network and never leaves your machine.

    2–4 seconds
  5. 5

    You paste a GitHub URL

    github.com/owner/repo, owner/repo or git@github.com:owner/repo.git. Only github.com is accepted.

    5 seconds
  6. 6

    It reads the repo and writes a plan

    Manifests such as package.json, requirements.txt, go.mod, Dockerfile, compose.yaml, pom.xml decide the steps: clone, virtualenv, dependencies, build, start. Each step shows the exact command and a risk label.

    3–15 seconds
  7. 7

    You approve, one step at a time

    Nothing runs until you click Approve and run — or approve the whole plan at once. You can skip optional steps and cancel mid-way. Output streams live into the console.

    as long as you want
  8. 8

    The project joins "My projects"

    Use Guide for a local explanation based on its manifests, start scripts, README instructions, and logs. Then press Run to launch the detected command. You can also update, open the folder, or inspect logs; approvals are still required for setup commands.

    whenever you need it

READ THIS BEFORE THE FIRST RUN

The Windows warning, explained.

We are not going to pretend it does not exist.

Why you see "publisher could not be verified"

SmartScreen trusts files that carry a code-signing certificate bought from a certificate authority and reputation built up over many downloads. This build is signed by nobody: it is an open-source project, and an Extended Validation certificate costs a few hundred dollars a year plus a registered company. Rather than delay the release, we publish the raw build and tell you the truth.

  1. Run the .exe. The blue window says "Windows protected your PC".
  2. Click More info — the text expands to show the publisher.
  3. Click Run anyway.
  4. If your antivirus still blocks it, add an exception for the install folder and report the file hash to us.

You can also skip the installer entirely: read the source and run it from Node.js (see Run from source). That path compiles nothing and installs nothing.

WHAT IT CAN AND CANNOT DO

The honest boundary.

Read this once and you will know exactly what is running on your machine.

What it does

  • Starts an HTTP server bound to 127.0.0.1 only, on a random port, for the lifetime of the window.
  • Requires a per-session token on every request; requests with a foreign Host header get 403, which blocks DNS-rebinding from any other page you have open.
  • Runs commands as an argument array with shell: false, so repository content is never parsed as shell syntax. On Windows, npm runs as node npm-cli.js to avoid npm.cmd.
  • Executes a step only after that exact step was approved in the UI.
  • Checks free disk space in your work folder before cloning, and warns or stops when it is critical.
  • Stores settings, project registry and logs in GUITinstal's local user-data folder.

What it does not

  • It has no telemetry or GUITinstal cloud account. Project guidance is local by default. If you opt in to external AI, your question, detected project details, relevant README instructions, and recent logs are sent to enabled providers you marked no-cost; a repair request also sends the selected file. The app cannot verify provider pricing or quotas. If you connect GitHub, the token is sent directly to GitHub over HTTPS for public API requests.
  • It does not listen on your LAN or the internet, so other devices on your network cannot reach it.
  • It does not install anything before you approve. There is no background updater and no scheduled job.
  • It does not request or access private GitHub repositories, and does not accept repository URLs from other git hosts.
  • It does not need admin rights; it installs into your user profile.

GitHub credentials are never written in plain text: Windows uses DPAPI, Linux uses Secret Service when available (otherwise the token stays in memory), and macOS currently keeps it in memory for the session.

Run GUITinstal from the download.

Extract the ZIP, then use Node.js 24 or newer. You can also clone the public repository with Git.

# After extracting the source ZIP: cd guitinstal-main/app node server/main.js --open # Or clone the public repository: git clone https://github.com/matheusiaengineer/guitinstal.git cd guitinstal/app node server/main.js --open

This runs GUITinstal locally and opens its interface in your browser. The app source and your projects stay on your computer. These source downloads work on Linux and macOS; they are not native installers.

To install Node.js without guessing commands for your Linux distribution, use the official Node.js download page. Git is available from your distribution's software manager.

CLEAN EXIT

Uninstall.

Your cloned projects are yours and stay on disk.

Setup build

  1. Windows Settings → Apps → Installed apps → GUITinstal → Uninstall.
  2. Or run Uninstall GUITinstal.exe from the Start menu folder.

Leftover data

Delete %APPDATA%\GUITinstal to remove settings and the project registry. Repositories you installed live in your work folder (default ~\GUITinstal-workspace) and are never touched by the uninstaller.

QUESTIONS

Frequently asked.

Including the awkward ones.

Does it work offline?

The app itself runs offline. Cloning and reading a repository obviously need internet, and so does downloading dependencies. Once a project is installed, starting it again is fully local.

Why did a step fail with "Are you sure (Y/N)"?

Some projects ship scripts that ask for confirmation — sindresorhus/is runs del distribution, which prompts on Windows. The app closes the input stream on purpose so nothing can wait for you unknowingly, which means such a step fails instead of hanging. Skip the step or run that one command yourself in a terminal.

Can it run a command I do not want?

No. The engine only executes a step after the UI marked it approved, and approval is per step. Cancelling stops the queue immediately.

Is my GitHub token sent anywhere?

When you sign in, it is sent directly to api.github.com over HTTPS to raise the public API limit and show your public repositories. GUITinstal does not request private-repository access. The token is protected by Windows DPAPI or the Linux desktop keyring when available; on macOS and systems without a usable Linux keyring it stays in memory for that session, never in plain-text settings.

Why is the installer 115 MB for such a small app?

Your app code is a few hundred kilobytes. The rest is the Chromium and Node runtime that Electron bundles so the window looks identical on every machine. A smaller build using the system webview is on the roadmap.

Where is the source code?

It is open source under the MIT licence. The repository link appears in the sidebar as soon as the public repo is published.

What is coming next?

Code signing, a queue of installs instead of one at a time, and a smaller runtime. See the roadmap in the repository.

KNOWN LIMITS

What is not perfect yet.

We would rather you find this list here than discover it at 1 a.m.

  • One installation at a time — there is no queue.
  • docker compose up needs docker on the PATH of the app process; Docker Desktop installs where that is not always true.
  • Maven, Gradle, .NET, Ruby, Docker and the C/C++ toolchains have no installer adapter yet: they are guided installs with the official page attached.
  • The runtime adapters are Windows only, so macOS and Linux are guided-only for every runtime.
  • Windows and macOS builds are unsigned; SmartScreen and Gatekeeper may warn before the first run.
  • Runtime installers are Windows-only. On macOS and Linux, missing runtimes must be installed from their official sources.
