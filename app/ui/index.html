    AI providers
    
            
    Add OpenAI-compatible inference endpoints and manage their priority here. FreeAPI is a catalog of public APIs, not an AI model. GUITinstal only tries providers you enable and explicitly mark no-cost. Free quotas and pricing can change; the app cannot verify a provider's billing policy. API keys stay in the OS secure store when available and are never returned to the page.
    
            
    
            
    
              
              
              
              
              
              
    Use the provider's OpenAI-compatible HTTPS base URL (usually ending in /v1); GUITinstal adds /chat/completions. Enter the model ID and API key exactly as the provider documents them.
